# 📋 دليل الترحيل: من لقطات الشاشة إلى الرسومات التفاعلية

## 🚀 البدء السريع (5 دقائق)

### الخطوة 1: نسخ الملفات الجديدة

```bash
# الملفات المطلوبة:
src/scenes/Scene5InteractiveScreens.tsx
src/screens/DashboardScreen.tsx
src/screens/TemplatesScreen.tsx
src/screens/DetailsScreen.tsx
src/screens/PreviewScreen.tsx
```

### الخطوة 2: تحديث المستوردات

في `src/MasrraAd.tsx`:

**قبل:**
```javascript
import { Scene5LiveScreens } from "./scenes/Scene5LiveScreens";
```

**بعد:**
```javascript
import { Scene5InteractiveScreens } from "./scenes/Scene5InteractiveScreens";
```

### الخطوة 3: تحديث المكون

في `src/MasrraAd.tsx`، في array `NOMINAL`:

**قبل:**
```javascript
{ from: 450, duration: 240, Comp: Scene5LiveScreens },
```

**بعد:**
```javascript
{ from: 450, duration: 240, Comp: Scene5InteractiveScreens },
```

### الخطوة 4: اختبر الفيديو

```bash
npm run dev
```

✅ **تم!** الآن يستخدم الفيديو الرسومات التفاعلية الجديدة.

## 🎯 الاختلافات بين الإصدارين

### Scene5LiveScreens (الأصلي - لقطات حقيقية)

```
✅ مميزات:
  - لقطات حقيقية من المنصة الفعلية
  - 100% دقة واجهة المستخدم
  
❌ عيوب:
  - حجم ملفات كبير جداً (صور PNG)
  - أداء أقل على الأجهزة الضعيفة
  - صعوبة التخصيص
  - تأثيرات محدودة (zoom فقط)
```

### Scene5InteractiveScreens (الجديد - رسومات تفاعلية)

```
✅ مميزات:
  - حجم ملفات صغير جداً (50-100 KB)
  - أداء عالية (60fps سلسة)
  - سهولة التخصيص (تغيير الألوان، الحركات)
  - تأثيرات متقدمة (3D، gradient، animations)
  
❌ عيوب:
  - واجهة مصممة، ليست نسخة دقيقة من الفعلية
  - تحتاج صيانة إذا تغيرت الواجهة الحقيقية
```

## 🎨 التخصيص بعد الترحيل

### تغيير الألوان لمناسبة أخرى

**مثال: تحويل الألوان للأزرق والذهب**

في `src/theme.ts`:

```javascript
// قبل (بنفسجي وذهبي):
export const colors = {
  accent: "#70508D",          // بنفسجي
  primary: "#70508D",
  decorativeGold: "#C7A15F",  // ذهبي دافئ
};

// بعد (أزرق وذهب):
export const colors = {
  accent: "#003D7A",          // أزرق غامق
  primary: "#003D7A",
  decorativeGold: "#FFD700",  // ذهبي ساطع
};
```

**النتيجة:** جميع الشاشات تنعكس الألوان تلقائياً ✨

- حجم الملف: ~2-4 MB

## 🐛 استكشاف الأخطاء

### المشكلة: الشاشات لا تظهر

**السبب:** ملفات المكونات غير محملة

**الحل:**
```bash
# تأكد من وجود الملفات:
ls src/screens/
# يجب أن تظهر:
# DashboardScreen.tsx
# TemplatesScreen.tsx
# DetailsScreen.tsx
# PreviewScreen.tsx
```

### المشكلة: أخطاء في الترجمة

**السبب:** استيراد خاطئ

**الحل:**
```javascript
// ✅ صحيح:
import { DashboardScreen } from "../screens/DashboardScreen";

// ❌ خطأ:
import DashboardScreen from "../screens/DashboardScreen";
import { DashboardScreen } from "./DashboardScreen"; // مسار خاطئ
```

### المشكلة: الحركات بطيئة أو متقطعة

**السبب:** ملفات كبيرة أو أجهزة ضعيفة

**الحل:**
```bash
# قلل عدد الخيوط:
npm run render -- --concurrency 2

# أو اختبر بدقة أقل:
npm run render -- --resolution 1280x720
```

### المشكلة: النصوص العربية مقلوبة

**السبب:** فقدان الدعم RTL

**الحل:**
```javascript
// أضف dir="rtl" على النصوص:
<div style={{ direction: "rtl" }}>
  النص العربي هنا
</div>
```
